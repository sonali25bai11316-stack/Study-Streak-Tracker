**PROJECT REPORT**  
**Study Streak Tracker**

**1\. Project Overview**

Study Streak Tracker is a console-based Java application designed to help students record and monitor their study activities. It allows users to track study sessions, calculate study streaks, view statistics, and set weekly study goals.

**2\. Problem Statement**

Students often find it difficult to maintain consistency and keep track of their study progress. This project provides a simple way to record study activities and monitor progress.

**3\. Objectives**

\- Record daily study sessions.  
\- Track total study time.  
\- Calculate study streaks.  
\- Set weekly study goals.  
\- Display study statistics.  
\- Demonstrate Java Object-Oriented Programming concepts.

**4\. Features**

\- Add study sessions  
\- View recorded sessions  
\- Calculate total study time  
\- Track current study streak  
\- Set weekly study goals  
\- View study statistics  
\- Manage achievements  
\- Console-based user interface

**5\. Technologies Used**

\- Java  
\- Object-Oriented Programming  
\- ArrayList  
\- LocalDate  
\- Scanner  
\- Standard Java Libraries  
\- Apache NetBeans IDE
