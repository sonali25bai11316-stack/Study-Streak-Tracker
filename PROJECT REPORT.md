# **STUDY STREAK TRACKER**

## 

## **1\. Project Overview**

Study Streak Tracker is a console-based Java application that helps students record study sessions, track study streaks, view study statistics, and set weekly study goals.

## 

## **2\. Problem Statement**

Students often find it difficult to maintain consistency and keep track of their study progress. This project provides a simple way to record and monitor daily study activities.

## 

## **3\. Features**

* Add study sessions  
* View recorded sessions  
* Track total study time  
* Calculate study streak  
* Set weekly study goals  
* View statistics and achievements  
* Local data storage  
* Input validation

## 

## **4\. Technologies Used**

* Java  
* Object-Oriented Programming  
* ArrayList  
* LocalDate  
* File Handling  
* Standard Java Libraries

## **5\. Objective**

The objective is to demonstrate the practical use of Java and OOP concepts by developing a simple student productivity application.

## 

## **6\. Results**

The application successfully records study sessions and calculates study time, streaks, and weekly goal progress through a command-line interface.

## 

## **7\. Learning Outcomes**

* Understanding of classes and objects  
* Encapsulation  
* ArrayList  
* File handling  
* Date handling  
* Exception handling  
* Console-based application development

## 

## **8\. Future Scope**

* GUI using Java Swing  
* Subject-wise statistics  
* Progress charts  
* Study reminders  
* Monthly reports

## 

## **9\. Conclusion**

The Study Streak Tracker demonstrates how basic Java and OOP concepts can be combined to create a useful and practical student productivity application.
