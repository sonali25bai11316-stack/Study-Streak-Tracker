**STUDY STREAK TRACKER**

**1\. Project Overview**

Study Streak Tracker is a beginner-friendly, console-based Java application designed to help students record their study sessions and monitor their study progress.

The application allows users to add study sessions, view recorded sessions, calculate their total study time, track their current study streak, view statistics, and set weekly study goals.

**2\. Problem Statement**

Students often study regularly but may find it difficult to keep track of their study time and maintain consistency.

The Study Streak Tracker provides a simple console-based solution for recording study sessions and monitoring study progress.

**3\. Features**

\- Add study sessions  
\- View recorded study sessions  
\- Track total study time  
\- Calculate current study streak  
\- Set weekly study goals  
\- View study statistics  
\- Display study duration and session dates  
\- Simple menu-driven interface  
\- Console-based interaction

**4\. Technologies Used**

\- Java  
\- Object-Oriented Programming (OOP)  
\- ArrayList  
\- LocalDate  
\- Scanner  
\- Standard Java Libraries

## **6\. Description of Classes**

### **StudySession.java**

Represents an individual study session. It stores information such as the subject, study duration, and date.

### **StudyTracker.java**

Manages the recorded study sessions and provides functions for calculating total study time, study streaks, statistics, and weekly goals.

### **StudyStreak.java**

Contains the main method and provides the menu-driven interface through which the user interacts with the application.

### **StudyStatistics.java**

Represents the statistics-related part of the study tracking system.

### **StudyGoal.java**

Represents the study goal functionality used for managing weekly study goals.

### **Achievement.java**

Represents achievement-related functionality for the study tracker.

## **7\. How the Application Works**

When the program starts, the user is presented with a menu:

1\. Add Study Session  
2\. View Study Sessions  
3\. View Statistics  
4\. Set Weekly Goal  
5\. Exit

### **Add Study Session**

The user enters:

* Subject  
* Study duration in minutes

The application records the session with the current date.

### **View Study Sessions**

Displays all recorded study sessions along with their subject, duration, and date.

### **View Statistics**

Displays:

* Total study time  
* Current study streak  
* Weekly study goal

### **Set Weekly Goal**

The user can enter a weekly study goal in minutes.

### **Exit**

Terminates the application.
